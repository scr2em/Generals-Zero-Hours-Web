Command & Conquer Generals: Zero Hour

WebAssembly port — two ways to play

Use my Zero Hour installation

Bring your own copy of the game. Select your Zero Hour folder, or the folder above it that holds your games (for example your Steam, EA app or Ultimate Collection library): the page finds what it needs. The game reads the files straight from that folder: nothing is copied, so the game files take no browser storage. Chrome asks you to allow access to the folder again on each visit. The files are copied once into this browser’s private storage.

Play with free starter content no game files needed

A small original placeholder game that ships with this port: one made-up faction, a few units and buildings, and one two-player skirmish map against the computer.

This is not Command & Conquer. It is an original stand-in game (code and art are free software, GPL-3.0-or-later) so the engine can be tried without owning anything.

Armies optional

Extra armies for skirmish games. Make them from a mod you own (right here in the browser), or keep them as .zharmy files in a folder and choose that folder. The game reads the ticked ones; nothing is uploaded.

Armies from a mod
Turns the armies of a mod you own into armies this game can use. The mod is only read.

Import armies from a mod

Choose the folder of the mod: either the mod’s own folder, or your Zero Hour folder if the mod is installed in it. The files are only read. Nothing is changed or uploaded.
